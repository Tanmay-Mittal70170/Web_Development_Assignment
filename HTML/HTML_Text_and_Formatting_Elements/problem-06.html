JavaScript:

JavaScript is a versatile, dynamically typed programming languagethat brings life to web pages by making them interactive. It is used for building interactive web applications and supports both client-side and server-side development.

1. Dynamically typed: Variable types are determined at runtime.

2. Single-threaded: Executes one task at a time (but supports asynchronous operations).

3. Compiled and interpreted: Modern JavaScript engines combine compilation and interpretation for better performance.

Some Examples for javascript: 

        
            1. console.log("Hello, World!"); {this is to print statement in javascript}
            2. let name= "Tanmay" {this is to insert the string}
            3. let age= 18 {here i have inserted int data type in variable age}

Now, Lets check one simple code of javascript: 

        
            let name = "Tanmay";
            let age = 18;

            console.log("Hello, " + name);
            console.log("Your age is " + age);

Java:

Java is a highly popular, high-level, object-oriented programming language designed to have as few implementation dependencies as possible. Developed by James Gosling at Sun Microsystems in 1995 (now owned by Oracle), it is structured around the core philosophy of "Write Once, Run Anywhere"

Some Examples of Java: 

        
            1. System.out.println("Hello World!"); {this is to print statement in java}
            2. int age = 18; {this is how we insert num value}
            3. str name= "Tanmay"; {this is to assign str to variable}

Now Let's check simple code of java: 

        
            public class Main {
    public static void main(String[] args) {

        int a = 10;
        int b = 20;

        int sum = a + b;

        System.out.println("Sum = " + sum);
    }
}
